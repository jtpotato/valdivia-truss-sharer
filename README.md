# Valdivia Truss Sharer

## Problem

Valdivia stores trusses in browser `localStorage`, which makes them awkward to copy, share, or move between devices.

## Solution

This small static site provides a simple text-based workflow:

1. Copy truss text out of Valdivia.
2. Paste it into the site and save it locally.
3. Copy the generated command back into Valdivia.
